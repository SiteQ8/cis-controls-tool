# Contributing

Contributions are welcome. This guide describes the process.

## Reporting Issues

When reporting bugs, include:
- Clear description of issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Browser and device information
- Screenshots if applicable

## Suggesting Features

Feature suggestions should include:
- Clear description of feature
- Use case and benefit
- Proposed implementation approach
- Examples from other tools if applicable

## Code Contributions

### Development Environment
- Text editor or IDE
- Node.js (optional)
- Git
- Modern web browser

### Making Changes
1. Fork repository
2. Create branch: `git checkout -b feature/feature-name`
3. Make changes
4. Test thoroughly
5. Commit: `git commit -m "Description of changes"`
6. Push: `git push origin feature/feature-name`
7. Submit pull request

### Code Standards
- Use ES6+ JavaScript
- Follow existing code style
- Add comments for complex logic
- Test on multiple browsers
- Test on mobile device
- Verify no console errors

### Testing
- Test in Chrome, Firefox, Safari, Edge
- Test on mobile device (iOS and Android)
- Test language toggle
- Test Arabic RTL layout
- Test export functions
- Verify data persistence

### Pull Request Guidelines
- Clear description of changes
- Reference related issues
- Include screenshots for UI changes
- Ensure all tests pass
- Keep commits organized

## Documentation

Documentation contributions welcome:
- Improve existing guides
- Add examples
- Fix typos
- Add translations
- Create tutorials

## Arabic Translations

When translating:
- Use professional cybersecurity terminology
- Maintain consistency with existing translations
- Test RTL layout
- Verify on mobile

## Review Process

All contributions reviewed for:
- Code quality
- Security implications
- Compatibility
- Testing
- Documentation

## Recognition

Contributors recognized in:
- Project contributors list
- Release notes
- GitHub acknowledgments

## Code of Conduct

- Respectful communication
- Professional tone
- No harassment or discrimination
- Focus on contribution quality
