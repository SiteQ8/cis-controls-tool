## Getting Started

### System Requirements
- Modern web browser
- JavaScript enabled
- localStorage enabled
- Screen size 320px or larger (mobile optimized)

### Supported Devices
- Desktop computers (Windows, macOS, Linux)
- Tablets (iPad, Android)
- Smartphones (iOS 12+, Android 5.0+)

### Language Selection
Toggle between English and Arabic in the application header. Data is preserved when switching languages.

## Creating an Assessment

### Step 1: Organization Profile
1. Click "New Assessment"
2. Enter organization name
3. Select sector (Financial, Healthcare, Government, Energy, Telecom, Manufacturing, Retail)
4. Choose organization size (Small, Medium, Large)
5. Select current maturity level
6. Choose target Implementation Group (IG1, IG2, or IG3)
7. Select regional focus (Kuwait, Saudi Arabia, UAE, Qatar, etc.)
8. Select compliance requirements (NIST, ISO 27001, SAMA, CBK, NCA-ECC, PCI-DSS, SWIFT)
9. Click "Continue to Assessment"

### Step 2: Assessment Details
Your profile is saved. Continue to Gap Analysis to evaluate controls.

## Gap Analysis

### Assessing Controls
1. Navigate to Gap Analysis tab
2. Review all 18 CIS Controls
3. For each control:
   - Review description and safeguards
   - Select implementation status:
     - Not Started (0%)
     - Planning (25%)
     - In Progress (50%)
     - Partially Implemented (75%)
     - Fully Implemented (100%)
   - Add notes or comments
4. System automatically calculates compliance score

### Understanding Results
- **Overall Compliance Score**: Percentage of controls fully implemented
- **Priority Gaps**: Top controls requiring attention
- **Priority Calculation**: Based on sector, organization size, and regional requirements
- **Effort Estimation**: Required resources for implementation

### Visualizations
- Horizontal bar chart: Control status overview
- Compliance gauge: Overall score
- Priority list: Top gaps identified

## Roadmap Generation

### Creating a Roadmap
1. Navigate to Roadmap tab
2. Select start date
3. Choose timeline duration (3, 6, 12, 18, 24, or 36 months)
4. Select resource allocation level
5. System generates phased roadmap

### Roadmap Phases
- **Phase 1 - Quick Wins**: High-priority, low-effort items
- **Phase 2 - Foundation**: Essential IG1 controls
- **Phase 3 - Enhancement**: IG2 implementation
- **Phase 4 - Advanced**: Complex controls and IG3
- **Phase 5 - Optimization**: Continuous improvement

### Customization
- Drag controls between phases
- Adjust timeline durations
- Add custom milestones
- Add implementation notes

## Framework Mapping

### Viewing Mappings
1. Navigate to Framework Mapping tab
2. Select frameworks (NIST CSF, ISO 27001, SAMA, CBK, NCA-ECC, PCI-DSS, SWIFT)
3. Choose visualization (Sunburst, Network, Matrix)
4. View CIS to framework alignment

### Understanding Mapping
- Identify framework requirements satisfied by CIS implementation
- Locate gaps requiring additional controls
- Assess implementation efficiency

### Regional Templates
- Kuwait Banking: CBK, SWIFT, PCI-DSS aligned
- Saudi Financial: SAMA, NCA-ECC aligned
- GCC Healthcare: ISO 27001, local requirements aligned

## Data Management

### Saving Data
- Assessment automatically saved to browser
- Data persists across sessions
- No manual save required

### Exporting Assessment
1. Navigate to Reports tab
2. Select export format (JSON, PDF, or Excel)
3. Choose language (English or Arabic)
4. Download file

### Importing Assessment
1. Navigate to Data Management
2. Select "Import Assessment"
3. Choose JSON file
4. Confirm import

### Assessment Comparison
1. Load previous assessment
2. Create new assessment
3. Navigate to comparison view
4. Review changes and progress

### Clearing Data
- Available in Settings
- Clears all local assessments
- Cannot be undone

## FAQ

**Q: Will this tool make my organization compliant?**
A: This tool helps plan and track CIS Controls implementation. Actual compliance requires implementing the controls and verification by auditors.

**Q: Can I use this on my mobile phone?**
A: Yes. The application is fully responsive and optimized for mobile devices including smartphones and tablets.

**Q: How long does an assessment take?**
A: Initial assessment typically requires 2-4 hours depending on organization size and preparedness.

**Q: Is my data secure?**
A: All data remains in your browser. No data is transmitted to external servers. You have full control over data export.

**Q: Which browsers are supported?**
A: Chrome, Firefox, Safari, and Edge are fully supported. Mobile browsers including iOS Safari and Chrome Mobile are supported.

**Q: Can I use this offline?**
A: The application requires initial internet connection. After loading, it works offline.

**Q: How do I export my assessment?**
A: Navigate to Reports tab, select export format (JSON, PDF, Excel), choose language, and download.

**Q: Can I compare assessments?**
A: Yes. Export your initial assessment as JSON, perform improvements, then import for comparison.

**Q: Does this tool include all 18 CIS Controls?**
A: Yes. All 18 CIS Controls v8.1 and 153 Safeguards are included.

**Q: Is Arabic supported?**
A: Yes. Complete bilingual support with full Arabic translation and RTL layout.
